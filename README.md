# Store Management System

A command-line store management system built with Python and JSON.

## Features

- Add new products
- Display available products
- Search products by name or category
- Edit product information
- Remove products
- Record sales
- View sales history
- Calculate total sales
- Manage product inventory
- Store data using JSON files

## Technologies

- Python
- JSON
- datetime

## Project Structure

```text
Store-Management-System/
│
├── main.py
├── products.json
├── sales.json
└── README.md
```
## How It Works
The application provides a command-line menu for managing products and recording sales.
Product information is stored in products.json, while sales records are stored in sales.json.
When a sale is recorded, the product quantity is automatically updated.
## How to Run
Clone the repository:
git clone YOUR_REPOSITORY_URL
Open the project folder:
cd Store-Management-System
Run the program:
python main.py
